# Электронный дневник (Android Studio)

Нативная Android-версия приложения «Электронный дневник», собранная под Android Studio (Kotlin, ViewBinding, Material Components).

## Структура

- **app/src/main/java/org/tged/electronicdiary/** — активити, фрагменты, `DataManager`, модели данных.
- **app/src/main/res/** — разметки, цвета, строки, темы.
- **app/src/main/assets/data.json** — данные (предметы, оценки, ДЗ).

## Как открыть и собрать

1. Откройте папку **AndroidAppStudio** в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle.
3. Подключите устройство или запустите эмулятор, нажмите Run.

## Экраны

- **Сводка** — список предметов с средним баллом и бейджами оценок.
- **ДЗ** — список домашних заданий (предмет, задание, срок, статус).
- **Предметы** — список предметов; по нажатию открывается экран оценок по предмету.
- **Поддержка** — текст с контактами в Telegram.

Данные читаются из `assets/data.json` при старте (тот же формат, что и в Qt-версии).
