# Электронный Дневник
Бот электронный дневник, дающий вам доступ к своим оценкам и домашним заданиям прямо в телеграмме
## Использование
Бот доступен по [ссылке](https://t.me/pss_ednevnik_bot)
### Настройка:
Что необходимо сделать, чтобы ваш класс мог пользоваться данным ботом

**Классный руководитель:**
- Убедиться что ваша школа использует ПО для выставления оценок "Параграф ДОУ"
- Узнать внешний адрес портала параграф (сайт, на котором вы можете выставлять оценки из дома. См раздел ниже)
- Открыть бота по ссылке и выбрать роль учителя
- Ввести необходимые данные
- Разослать каждому ученику ссылку-приглашение

**Ученик:**
- Перейти по ссылке от классного руководителя
- Проверить совпадает ли ФИО
- Использовать бота (/marks /dz)
## Принцип работы:
Бот работает без госуслуг и дополнительной авторизации. 
Это достигается за счет отправки запросов прямиком на сервер школы и авторизацией через классного руководителя.
Все оценки, домашние задания, файлы кэшируются на сервере бота. Тоесть доступ к оценкам будет даже если официальный портал будет вне сервиса

Сайт запускается с помощью библиотеки *Flask*

Сам бот работает благодаря библиотеке *python-telegram-bot*
## Как узнать внешнй адрес параграфа
Обычно этот адрес удвалетворяет структуре {тип школы}{номер}.online.{город}edu.ru

Типы школ:

- Гимназия - gym
- Лицей - lyc
- Cош - sch

например Гимназия 734 в Спб будет иметь адрес gym734.online.petersburgedu.ru
